# HTP Minsk (ПВТ) — Краулер контактов рекрутеров (Email & Telegram)

Многопоточный краулер на **Go** + генератор отчетов и интерактивного дашборда на **Python** для поиска работы **C# / .NET разработчиком**, **Go (Golang) разработчиком** или **Системным / Бизнес-аналитиком** (Junior / Middle) в компаниях-резидентах Парка высоких технологий (Минск).

## Как работает краулер ([main.go](file:///c:/Users/jotry/OneDrive/Desktop/поиск%20раюоты/main.go))

1. **Этап 1 — Сбор всех резидентов с `park.by`**:
   - Забирает полный список всех 1055+ резидентов из карты сайта `https://park.by/sitemap-iblock-170.xml`.
   - В 30 потоков обходит карточку каждой компании на `park.by/residents/...` и собирает:
     - Название и полное юр. наименование, УНП, город, адрес, размер штата (`11-50`, `51-100`, `101-500`, `501-1000`, `>1000`), год основания.
     - Официальный веб-сайт, телефон и контактный email из каталога ПВТ.
     - Направления деятельности (Разработка ПО, Системный анализ / бизнес-анализ и т.д.) и описание компании.
   - Кэширует результат в `residents_park_raw.json`.

2. **Этап 2 — Обход сайтов компаний и разделов `/career`, `/vacancies`, `/jobs`, `/contacts`**:
   - В 50 потоков заходит на официальный сайт каждого резидента.
   - Находит на главной странице ссылки на разделы **Career / Карьера / Вакансии / Jobs / Join Us / Контакты / О компании** (а если явных ссылок нет — проверяет типовые пути `/career`, `/careers`, `/vacancies`, `/jobs`, `/contacts`).
   - Извлекает:
     - **HR / Рекомендованные почты рекрутеров** (`hr@`, `job@`, `jobs@`, `career@`, `careers@`, `cv@`, `resume@`, `recruit@`, `talent@`, `people@`, `work@`, `rabota@` и др.), включая расшифровку защищенных Cloudflare `data-cfemail` и обфусцированных адресов вида `hr [at] company.by`.
     - **Telegram-контакты** (`https://t.me/...`, `tg://resolve?domain=...`, `@username` рядом с упоминанием Telegram/ТГ).
     - **Общие корпоративные почты** (`info@`, `office@`, `hello@`, `contact@` — полезны для небольших и средних компаний, где письма пересылаются напрямую HR).
     - **Ссылки на LinkedIn и job-борды** (`rabota.by`, `devby.io`, `hh.ru`, `career.habr.com`).
   - Определяет упоминания целевого стека и ролей:
     - `C# / .NET`
     - `Go (Golang)`
     - `System / Business Analyst` (Системный / Бизнес-анализ)
     - `Junior / Middle / Intern` (упоминания стажировок, джуниор/мидл позиций)

## Выходные файлы

- `htp_minsk_dashboard.html` — **интерактивная веб-таблица (дашборд)**: открывается прямо в браузере, позволяет фильтровать компании по стеку (`C# / .NET`, `Go`, `Системный аналитик`), наличию HR-почты или Telegram, размеру штата, а также в один клик копировать все HR-почты выбранных компаний для рассылки резюме.
- `htp_minsk_priority_hr_contacts.csv` — таблица (UTF-8 с BOM, разделитель `;` для удобного открытия в Microsoft Excel) с компаниями Минска, у которых найдены почты и/или Telegram, отсортированная по релевантности.
- `htp_minsk_all_contacts.csv` — полная CSV-таблица всех резидентов ПВТ.
- `TOP_COMPANIES_REPORT.md` — сводный Markdown-отчет с топ-компаниями ПВТ Минск, их HR-почтами, Telegram и ссылками на страницы карьеры.
- `htp_companies_contacts.json` — полная структурированная база данных в формате JSON.

## Повторный запуск

```powershell
# Сборка и полный запуск (использует кэш park.by, если он уже скачан)
.\htp-crawler.exe -park-workers 30 -site-workers 50 -max-pages 5

# Принудительное обновление данных с самого park.by
.\htp-crawler.exe -refresh-park -park-workers 30 -site-workers 50 -max-pages 6

# Перегенерация HTML-дашборда и Markdown-отчета
python generate_report.py
```
